# CRASH RIDE

物理演算エンジン Matter.js を使った、2D横スクロールの自転車アクションゲームです。
自転車も人も物理演算で動き、ぶつかり方によって毎回ちがう転び方をします。
トラップだらけのコースをぬけて、ゴールをめざします。

## 遊び方

1. `index.html` をダブルクリックして、ブラウザ（Chrome / Edge など）で開く
2. 乗り物をえらぶ（クリック、または 1 / 2 / 3 キー）
3. 「START」でメインコース、「日本全国チャレンジ」で都道府県ステージ

## 日本全国チャレンジ

47都道府県を地方ごとに並べた画面から、県をえらんで遊びます。今遊べるのは **大阪** だけで、ほかの県は「COMING SOON」です。
県ごとに、コースの形・ギミック・死亡メッセージ・死亡演出がちがいます。クリアタイムと死亡回数のベストは県ごとに記録されます（ブラウザに保存）。

### 大阪「なんでやねん！ 食いだおれサーキット」（チェックポイント5つ）

1. **道頓堀** → **戎橋**（渡ると崩れる。落ちると道頓堀にダイブ）→ **CP1**
2. **串カツ通り**：地面から串カツがリズムよく飛び出す。串の手前はソースでツルツル（ブレーキもアクセルもきかない）。かわいた地面で止まって、串が引っこむタイミングでソースの上をすべりこむ → **CP2**
3. **たこ焼き坂**（長い下り坂）：上りきると、後ろから巨大たこ焼きが猛スピードで追いかけてくる（止まるとひかれる）。背景のたこ焼き職人がたこ焼きをひっくり返すたびに、画面の奥からたこ焼きが飛んでくる（落ちる場所に影が出る）。最後に巨大たこ焼きは鉄板の穴に「スポッ」とはまる → **CP3**
4. **ツッコミ通り**：巨大ハリセンが「なんでやねん!」とたたきおろす。ふり上げている間にぬける → **CP4**
5. **テーマパーク**：フリーフォールに乗って上へ。上で止まった「いまや！」のうちにジェットコースターへ。急降下 → 水面すれすれ（**川からサメが飛び出して食べられる**。手前で止まって、サメが飛んだあとに走りぬける）→ こぶ → チェーンリフト（自動で上がる）→ 2回目の急降下 → レールの切れ目をジャンプ → **CP5**
6. **ボス「たこ焼き大王」**：タコ足が左から順番にたたきつけてくる。たこ焼きも飛ばしてくる。タコ足の波のすぐ前を走りぬけてゴール

死ぬと「なんでやねん!!」の文字と「ズコー」の音が出て、死亡画面は「アカン!!」になります。

## メインコース（進むほど難しくなる）

1. でこぼこ道 → シーソー → ジャンプパッドで落とし穴をこえる → 谷の振り子ノコギリ → **CP1**
2. 崩れる橋（上で上下するノコギリ）→ エレベーター → 転がってくる岩から逃げる急な下り坂 → 落とし穴 → **CP2**
3. ダブルハンマー → 柱わたり（すき間がだんだん広くなる）→ **CP3**
4. 崩れる足場（上で振り子ノコギリ）→ **CP4**
5. 急な上り坂 → ジャンプパッドでトゲの谷をこえる → **CP5**
6. 巨大ハンマー → ゴール？ → **CP6**
7. 「ここから先は安全」→ **CP7**
8. トンネル → まっすぐな道 → **CP8**
9. 見晴らしの丘 → 本当のゴール

後半（6〜9）は**初見殺し**のエリアです。一度死んで覚えてください。

### コツ

- ハンマー・振り子ノコギリは、一番下を通りすぎて**右へ振れていった直後**に進む
- 崩れる橋・崩れる足場は止まらずに一気に走りぬける（ノコギリのタイミングは手前で待って合わせる）
- エレベーターは、下に来たら乗って**すぐ Space で止まる**。一番上まで上がったら降りる
- 岩が出てきたら止まらずに走る。ただし速すぎると、坂の先の落とし穴のむこうで着地に失敗する
- ジャンプ中は ↑↓ で車体を地面と平行にしてから着地する

## 死亡・転倒の条件

- 頭を強く打つ／体に強い衝撃を受ける
- ノコギリ・トゲに体がふれる（車輪だけならトゲはセーフ。ただし飛び出すトゲに突っこむと投げ出される）
- ハンマー・プレス機・砲弾に当たる
- 地雷の爆発に巻きこまれる
- 高いところから落ちて、激しく着地する
- 落とし穴に落ちる
- ひっくり返ったまま1.2秒たつ、または軽い衝突で自転車から投げ出される

## しくみ

- `game.js`：物理演算・乗り物・ギミック・描画・画面。メインコース（`MAIN_COURSE`）もここ
- `stages.js`：都道府県ステージのデータ（`STAGES`）と、47都道府県の一覧（`PREFECTURES`）


- **乗り物**：`VEHICLES` に、車体の部品・車輪の位置と大きさ・人の姿勢・速さなどをまとめている。車体の部品をまとめた1つのボディ＋前輪・後輪（円）＋ペダル。車輪は Constraint（やわらかいばね）で車体につながる。大きさのちがう車輪（車いす）は、表面の速さがそろうように回す
- **ラグドール**：頭・胴体・上腕×2・前腕×2・太もも×2・すね×2 を Constraint の関節でつなぐ
- **補助 Constraint**：おしり→サドル、手→ハンドル、足→ペダルなど。強い衝突で外れて、人が投げ出される
- **ダメージ**：ぶつかった速さと、ぶつかった部位（頭・胴体・手足）で、「何もなし／投げ出される／死亡」が決まる（`DAMAGE`）
- **トラップ**：ハンマー・動く足場・動くノコギリ・プレス機・飛び出すトゲは「とても重いボディ」を決まった動きで動かしているので、ぶつかったものは物理演算で吹き飛ぶ。プレス機と飛び出すトゲは、自転車が `trigger` の位置をこえたときに動き出す
- **地雷**：すり抜けるセンサーのボディ。ふれると作動して、`fuse` 秒後に爆発する。爆発の近くにいると死亡、少しはなれていると吹き飛ばされる（`BLAST_KILL`、`BLAST_PUSH`）
- **大砲**：自転車が少し先に進む場所を計算して、ちょうどそこに落ちる速さで砲弾を撃つ
- **血しぶき**：最大500個まで。地面に落ちると跡が残り、12秒で消える
- **効果音**：Web Audio API で作っている（音声ファイルなし）

## 調整のヒント

`game.js` の最初にある数字で、遊びやすさを変えられます。

- `VEHICLES` の中の数字（乗り物ごと）
  - `maxSpin`：最高速度
  - `lift`：地面で傾ける強さ（大きいとウィリーしやすく、ひっくり返りやすい）
  - `airLean`：空中で傾ける強さ
  - `landEject` / `landFatal`：どのくらいの速さで着地すると投げ出される・死亡するか
- `DAMAGE`：どのくらいの衝撃で投げ出される・死亡するか
- メインコースは `MAIN_COURSE` の中（`lands`、`ramps`、`saws`、`hammers`、`platforms`、`mines`、`crushers`、`popSpikes`、`cannons` など）

## 新しい県を追加するには

`stages.js` だけを書きかえます（`game.js` はさわらなくてOK）。

1. `STAGES.okayama = { ... }` のように、大阪と同じ形でステージを書く
   - `theme`：空・建物・窓・地面・レールの色、遠くの景色
   - `death`：死亡画面のタイトル（`title`）、ひとこと（`lines`）、死んだ場所に出る文字（`bubbles`）、音（`sound`）
   - `clear`：クリア画面のタイトルとひとこと
   - `course`：コース。メインコースと同じ部品に加えて、次の部品が使える
     - `water`（落ちたら死ぬ水）、`slippery`（ツルツルの地面）、`sharks`（水から飛び出すサメ）
     - `depthShots`（背景の職人が、画面の奥から投げてくる）、`platforms` の `motion: "droptower"`（フリーフォール）
     - `ramps` の5つ目に `{ lift: 速さ }`（チェーンリフト）、`boulders` の `chase`（ずっと追いかけてくる）
   - 部品ごとに `death: "…"`（死亡メッセージ）、`kind`（見た目）を書ける
     - `boulders` / `cannons` の `kind: "takoyaki"` → たこ焼き（岡山の桃などは、同じように見た目を追加する）
     - `hammers` の `motion: "slap"` → ふり上げてたたく動き（`kind: "harisen"` でハリセン）
     - `crushers` の `auto: true` → 最初から上下をくりかえす（`kind: "tentacle"` でタコ足）
     - `popSpikes` の `period` → リズムよく飛び出しつづける（`style: "kushi"` で串カツ）
   - `decor`：当たり判定のない飾り（`lanterns` 提灯、`neon` ネオン、`globe` 地球儀、`ferris` 観覧車、`coaster` ループするコースター、`fins` サメのヒレ、`boss` たこ焼き大王）
2. `PREFECTURES` のその県を `["岡山", "okayama"]` のように書きかえる → 選択画面で遊べるようになる
