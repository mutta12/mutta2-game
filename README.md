# CRASH RIDE

物理演算エンジン Matter.js を使った、2D横スクロールの自転車アクションゲームです。
自転車も人も物理演算で動き、ぶつかり方によって毎回ちがう転び方をします。
トラップだらけのコースをぬけて、ゴールをめざします。

## 遊び方

1. `index.html` をダブルクリックして、ブラウザ（Chrome / Edge など）で開く
2. 「START」を押す

※ Matter.js をインターネットから読み込むので、**ネットにつながった状態**で開いてください。
※ 効果音が鳴ります。音量に気をつけてください。

## 操作

| キー | 動き |
| --- | --- |
| → / D | 前進・加速 |
| ← / A | 後退 |
| ↑ / W | 車体を後ろに傾ける（ウィリー） |
| ↓ / S | 車体を前に傾ける |
| Space | ブレーキ |
| R | 最初からやり直す |
| Enter | （死んだあと）チェックポイントから再開 |
| P / 右上の II ボタン | 一時停止 |

## コース（進むほど難しくなる）

1. でこぼこ道 → シーソー → ジャンプパッドで落とし穴をこえる → 谷の振り子ノコギリ → **CP1**
2. 崩れる橋（上で上下するノコギリ）→ エレベーター → 転がってくる岩から逃げる急な下り坂 → 落とし穴 → **CP2**
3. ダブルハンマー → 柱わたり（すき間がだんだん広くなる）→ **CP3**
4. 崩れる足場（上で振り子ノコギリ）→ **CP4**
5. 急な上り坂 → ジャンプパッドでトゲの谷をこえる → **CP5**
6. 巨大ハンマー → ゴール

### コツ

- ハンマー・振り子ノコギリは、一番下を通りすぎて**右へ振れていった直後**に進む
- 崩れる橋・崩れる足場は止まらずに一気に走りぬける（ノコギリのタイミングは手前で待って合わせる）
- エレベーターは、下に来たら乗って**すぐ Space で止まる**。一番上まで上がったら降りる
- 岩が出てきたら止まらずに走る。ただし速すぎると、坂の先の落とし穴のむこうで着地に失敗する
- ジャンプ中は ↑↓ で車体を地面と平行にしてから着地する

## 死亡・転倒の条件

- 頭を強く打つ／体に強い衝撃を受ける
- ノコギリ・トゲに体がふれる（車輪だけならトゲはセーフ）
- ハンマーに当たる
- 高いところから落ちて、激しく着地する
- 落とし穴に落ちる
- ひっくり返ったまま1.2秒たつ、または軽い衝突で自転車から投げ出される

## しくみ（game.js）

- **自転車**：車体フレーム・ハンドル・サドルをまとめた1つのボディ＋前輪・後輪（円）＋ペダル。車輪は Constraint（やわらかいばね）で車体につながる
- **ラグドール**：頭・胴体・上腕×2・前腕×2・太もも×2・すね×2 を Constraint の関節でつなぐ
- **補助 Constraint**：おしり→サドル、手→ハンドル、足→ペダルなど。強い衝突で外れて、人が投げ出される
- **ダメージ**：ぶつかった速さと、ぶつかった部位（頭・胴体・手足）で、「何もなし／投げ出される／死亡」が決まる（`DAMAGE`）
- **トラップ**：ハンマー・動く足場・動くノコギリは「とても重いボディ」を決まった動きで動かしているので、ぶつかったものは物理演算で吹き飛ぶ
- **血しぶき**：最大500個まで。地面に落ちると跡が残り、12秒で消える
- **効果音**：Web Audio API で作っている（音声ファイルなし）

## 調整のヒント

`game.js` の最初にある数字で、遊びやすさを変えられます。

- `MAX_SPIN`：最高速度
- `LIFT_FORCE`：地面で傾ける強さ（大きいとウィリーしやすく、ひっくり返りやすい）
- `AIR_LEAN_POWER`：空中で傾ける強さ
- `DAMAGE`：どのくらいの衝撃で投げ出される・死亡するか
- コースは `COURSE` の中（`lands`、`ramps`、`saws`、`hammers`、`platforms` など）
